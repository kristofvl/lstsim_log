# LSTSim Event Logging
Short HowTo:
- Download this directory and load as an unpacked browser extension in your browser
- Start a game in LSTSim.de. You should see the status of the extension in the upper right corner
- After a game, right-click on the LST extension button and select Options
- There, click "Legacy-Export (altes Format)" to download your game data in the original format
- Open the viz.html and load that file there to visualize
- "Export + Alles Löschen" downloads everything as a ZIP (new format plus the legacy file) and then clears the stored data
