# LSTSim Event Logging
Short HowTo:
- Download this directory and load as an unpacked browser extension in your browser
- Start a game in LSTSim.de. You should see the status of the extension in the upper right corner
- After a game, right-click on the LST extension button and select Options
- There, click the export+clear button to export your game data
- Open the viz.html and load the data there to visualize
